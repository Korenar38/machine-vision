Сессия 6. Готовые языковые модели: не обучаем, а используем.

В сессии 5 мы сами собрали мини-GPT (0,8 млн весов). Теперь берём готовые модели, которые обучали недели на огромных текстах,
и решаем с ними практические задачи: тон и эмоции текста, поиск по смыслу, определение жанра, генерация текста, чат-бот.
Всё работает на обычном процессоре, видеокарта не нужна.

Каждый шаг есть в двух видах: скрипт .py и ноутбук .ipynb с подробными пояснениями.
Запускайте по порядку из папки session06.

01_models_and_tokens — откуда берутся готовые модели (Hugging Face Hub), сколько в них весов, как три разные модели режут один текст на токены.
02_sentiment_emotions — готовые классификаторы тона и эмоций; что внутри pipeline; где модели ошибаются (сарказм, отрицание);
                        эмоциональная «кардиограмма» «Евгения Онегина».
03_meaning_vectors — фраза → вектор смысла; тепловая карта близостей, карта смыслов (PCA), поиск по смыслу против поиска по словам.
04_genre_classifier — главный шаг: определяем жанр, обучая один слой Linear поверх готового BERT (сохраняет genre_head.pt);
                      сколько нужно примеров, матрица ошибок, почему BERT не узнаёт стихи «Онегина».
05_whats_inside — что видит модель: угадывание пропущенного слова, стереотипы («[MASK] работает врачом»),
                  слово в контексте (лук в супе и лук охотника — разные векторы).
06_real_gpt — настоящий GPT (ruGPT-3 small): вероятности следующего слова, жадный выбор / температура / top-k / top-p,
              сравнение loss с мини-GPT из сессии 5, подсветка «неожиданных» слов.
07_tiny_chatbot — маленький чат-бот Qwen 0.5B: что такое чат изнутри, системная подсказка, жанр без обучения,
                  JSON из текста, галлюцинации; по желанию — сравнение с Qwen 1.5B. На процессоре ответ — от секунд до минуты.
08_bonus_text_analyzer — бонус и мини-проект: все модели вместе анализируют любой текст.
Методические_указания.md — для преподавателя: цели, ход занятий, вопросы классу, ответы к заданиям.
План_занятий.md — общий план сессии.
common.py — общие части: загрузка моделей, векторы фраз (Embedder), тексты по жанрам и «Онегин».
genres.csv — 120 коротких отрывков шести жанров (написаны для курса): сказка, детектив, фантастика, стихи, новости, научпоп.

Что нужно установить:
   pip install -r requirements.txt
(дополнительно к прошлым сессиям нужен пакет transformers).

Модели скачиваются сами при первом запуске каждого шага в папку data/hf (нужен интернет), дальше работают без интернета:
   rubert-tiny2 и два классификатора на её основе — 3 × 115 МБ (шаги 2–5, 8)
   ruGPT-3 small — 530 МБ (шаги 1, 5, 6, 8)
   Qwen2.5-0.5B-Instruct — 950 МБ (шаги 1, 7, 8)
   Qwen2.5-1.5B-Instruct — 3 ГБ, только по желанию для сравнения в шаге 7 (пункт 5); нужно ~6 ГБ оперативной памяти.
Итого около 1,8 ГБ (с моделью 1.5B — около 4,8 ГБ). Для занятий без интернета заранее запустите шаги 1 и 2
(вместе они скачивают все основные модели) или скопируйте папку data/hf с флешки.

Шагу 6 для сравнения нужна мини-GPT из сессии 5 (session05/gpt.pt); без неё шаг тоже работает.
Шагу 8 нужна голова жанров из шага 4 (genre_head.pt); если её нет, шаг обучит её сам за несколько секунд.

Для Google Colab: положите папку session06 рядом с session05 в machine_vision на Google Диске;
первая ячейка каждого ноутбука подключит Диск и установит transformers. Модели скачаются в machine_vision/data/hf на Диске.
