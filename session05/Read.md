Сессия 5. Языковые модели своими руками: от подсчёта букв до мини-GPT.

Данные — список русских имён (names.txt) и «Евгений Онегин» А. С. Пушкина, главы 1–8 (onegin.txt, текст из Викитеки, общественное достояние).
Оба файла лежат в этой папке, интернет не нужен. Всё обучается на обычном процессоре, видеокарта не нужна.

Каждый шаг есть в двух видах: скрипт .py и ноутбук .ipynb с подробными пояснениями.
Запускайте по порядку из папки session05.

01_text_is_numbers — текст как числа: словарь символов, словарь слов, склейка частых пар (BPE) — сначала на игрушечном примере.
02_bigram_counts — самая простая языковая модель: таблица «какая буква за какой», придумываем имена, вероятность имени, loss.
03_bigram_neural — та же биграмма как нейросеть (nn.Embedding), один шаг градиентного спуска под лупой, обучение.
04_temperature — как выбирать следующий символ: температура, жадный выбор, качество против разнообразия.
05_attention_by_hand — внимание своими руками: пример на пальцах, маска, Q/K/V, зачем √d, порядок слов, несколько голов.
06_mini_gpt — маленький трансформер учится писать «как Пушкин» (сохраняет gpt.pt, gpt.json; 3–6 минут);
              заглядываем внутрь: следующий символ, веса внимания, списывает ли модель.
07_bonus_clip_vs_cnn — бонус: CLIP отличает кошек от собак без обучения; сравнение с сетями сессии 4, поиск картинок по тексту.
Методические_указания.md — для преподавателя: цели, теория, ход занятия, вопросы классу и ответы к заданиям шагов 1–6.
common.py — общие части: загрузка текстов, словарь символов, биграммы, температура, MiniGPT.

Бонусный шаг 07 требует дополнительно:
1. Пакет clip (код OpenAI CLIP в сборке Ultralytics, тот же, что использует YOLO-World):
   pip install git+https://github.com/ultralytics/CLIP.git
   Для установки без интернета заранее соберите колёса: pip wheel --wheel-dir wheelhouse git+https://github.com/ultralytics/CLIP.git
2. Веса ViT-B-32.pt (~340 МБ) в папке data/clip. Скачиваются сами при первом запуске шага 07 (нужен интернет),
   дальше берутся локально. Для занятий без интернета положите этот файл в data/clip заранее.
3. Обученные сети session04/mlp.pt, cnn.pt, cnn_aug.pt (шаги 3–5 сессии 4) — для сравнения; без них шаг тоже работает.
