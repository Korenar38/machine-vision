Сессия 4. Простые свёрточные сети: кошки против собак.

Данные — кошки и собаки из CIFAR-10 (цветные картинки 32×32: 10 000 для обучения, 2 000 для проверки).
Набор берётся локально из папки data/cifar-10-batches-py (интернет не нужен). Всё обучается на обычном процессоре, видеокарта не нужна.

Каждый шаг есть в двух видах: скрипт .py и ноутбук .ipynb с подробными пояснениями.
Запускайте по порядку из папки session04: шаги 4–7 используют сети, обученные на предыдущих шагах.

01_look_at_cats_dogs — смотрим на данные: форма тензора, цветовые каналы, чем задача сложнее MNIST.
02_convolution_by_hand — свёртка своими руками: ручные ядра, ReLU, пулинг, слой nn.Conv2d и его веса.
03_mlp_baseline — точка отсчёта: полносвязная сеть из сессии 3 (сохраняет mlp.pt, mlp.json).
04_train_cnn — простая свёрточная сеть: три блока «свёртка → ReLU → пулинг», переобучение (cnn.pt, cnn.json).
05_augmentation_dropout — боремся с переобучением: аугментация и dropout (cnn_aug.pt, cnn_aug.json).
06_what_cnn_sees — фильтры первого слоя, карты признаков, точность по классам, самые уверенные ошибки.
07_your_photo — проверка на своих фото: положите jpg/png в папку my_photos.
common.py — общие части: набор CatsDogs, сети MLP и SimpleCNN, цикл обучения, сохранение и загрузка.
